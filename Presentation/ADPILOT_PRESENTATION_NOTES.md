### Slide 14: Dual-Stream Hybrid RAG & Multi-Tier Memory
- **Title:** Dual-Stream Hybrid RAG & Multi-Tier Agent Memory
- **Purpose:** Explain how dense semantic vectors and sparse lexical search combine with 4-tier memory.
- **Main Message:** Reciprocal Rank Fusion ensures 100% retrieval recall and zero hallucination.
- **Speaker Notes:**
  > *"To ground all agent decisions in verifiable company facts, we engineered a Dual-Stream Hybrid RAG engine. Furthermore, our 4-tier memory architecture isolates active working memory, brand guidelines, customer personas, and RL feedback history."*
- **Technical Explanation:**
  RRF formula: $RRF(d) = \sum_{m} \frac{w_m}{k + r_m(d)}$. Dense vectors capture semantic intent, while BM25 captures exact product names and SKU codes.
- **Potential Question:** *"Why use Reciprocal Rank Fusion instead of standard vector search alone?"*
- **Suggested Answer:** *"Pure vector search frequently misses exact keyword queries such as specific product model numbers. Hybrid RRF combines the semantic strengths of embeddings with the precision of lexical matching."*

### Slide 15: Reinforcement Learning: Continuous PPO Architecture
- **Title:** Continuous PPO Actor-Critic Policy Architecture
- **Purpose:** Detail the mathematical formulation of the PPO continuous state space, action simplex, and clipped surrogate loss.
- **Main Message:** ADPilot Pro uses Proximal Policy Optimization to solve continuous multi-channel budget allocation under safety constraints.
- **Speaker Notes:**
  > *"For budget optimization, ADPilot Pro implements Proximal Policy Optimization over a 12-dimensional continuous state space. The state space captures channel weights, predicted ROAS, CAC, CTR, and market penetration. The action space represents budget weight changes bounded on the standard simplex. Our reward objective maximizes marginal ROAS gains while penalizing CAC inflation and volatility. Clipped surrogate loss with $\epsilon = 0.2$ ensures policy update stability."*
- **Technical Explanation:**
  Policy network: Actor-Critic MLP with Gaussian continuous action distribution projected onto Dirichlet simplex constraints ($\sum a_k = 1.0$, $a_k \ge 0.05$).
- **Potential Question:** *"Why use PPO instead of Q-Learning or DQN?"*
- **Suggested Answer:** *"DQN is limited to discrete action spaces (e.g. choose channel A or B). Marketing budget allocation is a continuous multi-dimensional optimization problem ($\Delta^K$) requiring continuous Actor-Critic policy gradient methods like PPO."*
